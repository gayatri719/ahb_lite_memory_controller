# 🧠 AHB-Lite Memory Controller (RTL → GDSII)

### 📘 Overview
This project implements an **AHB-Lite Memory Controller** using **Verilog HDL**, with complete **functional verification**, **synthesis**, and **GDSII layout generation** using **Cadence Virtuoso** (semi-custom flow).  
The controller supports simple read/write memory-mapped transactions compatible with the **AMBA AHB-Lite protocol**.

---

### ⚙️ Features
- ✅ AHB-Lite compliant interface  
- ✅ 32-bit data width and 256 x 32-bit internal memory  
- ✅ Single-cycle read/write transactions  
- ✅ Fully synthesizable RTL  
- ✅ Post-synthesis and layout (GDSII) generation using Cadence tools  
- ✅ Simple testbench for functional verification
